# Bandera de Turquía con JOGL

Proyecto realizado en Java utilizando JOGL para representar gráficamente la bandera de Turquía.

## Elementos utilizados

- Java
- JOGL
- OpenGL
- Maven

## Descripción

El programa dibuja la bandera de Turquía mediante primitivas gráficas de OpenGL.

La bandera está formada por:

- Fondo rojo.
- Media luna blanca.
- Estrella blanca de cinco puntas.

## Ejecución

El proyecto fue desarrollado en Apache NetBeans utilizando Java y Maven.

La clase principal es:

`BanderaTurquia.java`

## Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir Apache NetBeans.
3. Ir a: `File > Open Project`
4. Seleccionar la carpeta del proyecto `BanderaTurquia`.
5. Esperar a que Maven descargue automáticamente las dependencias de JOGL.
6. Abrir el archivo: `src/main/java/com/mycompany/banderaturquia/BanderaTurquia.java`
7. Ejecutar el programa con: `Shift + F6` o presionar el botón **Run File** de NetBeans.
8. Se abrirá una ventana mostrando la bandera de Turquía realizada con JOGL.
